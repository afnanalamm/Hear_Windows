## Introduction

Hear is a social awareness application. It aims to inform and educate users about various social issues through an interactive and user-friendly interface, and allows them to launch, and sign, petitions on a government-recognised platform. The app is developed using Python and leverages libraries such as Tkinter for the GUI, PIL for image processing, and Pandas for data manipulation.

## Features

- **Interactive GUI:** Easy-to-use interface built with Tkinter and CustomTkinter.
- **Image Processing:** Utilizes PIL for handling and displaying images.
- **Data Handling:** Uses Pandas for managing and processing data.
- **Educational Content:** Provides information and resources on various social issues.
